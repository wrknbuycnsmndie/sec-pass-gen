# SecPassGen

A lightweight password generator built with Astro and plain CSS.

## Stack

- Astro
- TypeScript
- Plain CSS
- Node test runner

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
npm run test
```

## Notes

- Password generation logic lives in `src/lib/password.ts`.
- Browser preferences live in `src/lib/preferences.ts`.
- The site uses static HTML/CSS with a tiny client script.
