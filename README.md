# Password Generator (inspired by LastPass)

This project was developed primarily for personal use by me and my gf. It serves as a simple tool, nothing so special.

## Goals (or why it was created)

The primary goal of mine was to experiment with ShadCN themes, which were recommended in some chats discussions. It looks cool, simple to use in your projects, and very usable with Tailwind CSS.

## Technology Stack

- **Framework**: Next.js (Pages Router)
- **State Management**: Zustand
- **UI Components**: ShadCN
- **Animations**: Motion
- **Language**: TypeScript
- **CSS**: Tailwind v4

## How to run

Just run this in console

```
npm run dev
```

and you're here buddy!

## How to build

```
npm run build
```
